## Цикл на каждый этап (M1 → M2 → M3 → M4)
1. Фронт делает этап, отчитывается.
2. Судья проверяет ветку фронта (код, тесты, сборки, эмулятор, снимки/записи, бриф, стандарты анимаций) →
   вердикт PASS/FAIL со списком в `.claude/ui-redesign/reviews/<этап>-r<N>.md`.
3. FAIL → фронту список замечаний (SendMessage), он чинит → судья перепроверяет (тот же агент, SendMessage).
   Максимум 3 круга на этап, потом — дальше с открытыми замечаниями в PROGRESS.md.
4. PASS → фронту следующий этап.
5. УСКОРЕНИЕ (пользователь 2026-10-26 ~15:40): если в вердикте 0 блокирующих и 0 важных (только мелкие) — этап
   считается принятым; мелкие отдать фронту вместе со следующим этапом, ПЕРЕПРОВЕРКУ НЕ ЗАПУСКАТЬ.
   Блокирующие или важные — повторный круг как раньше.
Эмулятор один (AVD nova): фронт и судья не запускают его одновременно.
