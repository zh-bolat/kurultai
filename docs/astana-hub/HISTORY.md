# Astana Hub Robot — что мы сделали (15–29 октября 2026)

Готовый голосовой робот-помощник технопарка Astana Hub на OrionStar GreetingBot Nova. Код: `~/astana-hub-robot`,
GitHub `zh-bolat/astana-hub-robot` (публичный с 29.10, `main` = продукт, рабочая ветка `feature/voice-latency`).
Команда: пользователь (zh-bolat, тимлид), mynbay (дизайн/прототип), Collector119 (агентский чат). Разработка велась
через Claude Code: главный агент + субагенты `frontend` / `backend` / `devops`, на этапе редизайна — фронт на Opus 5.5
и независимый судья на Fable 5.1.

## Как это устроено (итог)
```
Посетитель ─ голос ─► Android-приложение (Compose, движок лица на Canvas)
   ├─ «где X», «проводи» → карта и навигация робота (RobotAPI), без сети
   ├─ камера SurfaceShareApi → /v1/look
   └─ WS /v1/live (голос туда-обратно; запасной путь /v1/chat SSE + /v1/stt + /v1/tts)
Сервер (FastAPI + Pipecat): VAD → STT (Gemini Flash Lite via OpenRouter) → агент (Claude Haiku 5.5, поиск по базе до ответа)
   → ElevenLabs Dmitry v4 Turbo (нормализация текста, кеш фраз) → звук роботу
Postgres 16 + pgvector: база знаний, фрагменты, сессии/история, журнал вопросов, метрики
```
Ключи только на сервере. Контракт — `api-contract.md` v1.4.

## Цифры
- Тесты: сервер 956, приложение 1795 (две сборки). CI зелёный.
- Стоимость: ~$0.001 OpenRouter на ответ; ~20 кредитов ElevenLabs на ответ (0,2 кредита/символ на v4 Turbo);
  при 150 ответах в день ≈ 16–18 тыс. ₸/мес (ElevenLabs Creator $22 + OpenRouter $3–5 + VPS 3–4 тыс. ₸).
- Балансы на 29.10: OpenRouter — новый ключ с лимитом $5; ElevenLabs Starter 40k кредитов/мес (осталось ~33k).

## Решения, которые стоит помнить
- Дизайн — **точь-в-точь прототип mynbay** (`design/robot-mvp.html` @ 483f1fd, v9). Отличия только там, где функция
  иначе не работает; все они перечислены в `ui-redesign/INTEGRATION.md` §0.4–0.6.
- Сон по тапу вместо «всегда слушает» — ответ на шумный холл. Тап по лицу робота не перебивает; «Стоп» — на странице.
- Экраны лицо ↔ приложение меняются только свайпом, без таймеров и автопереходов.
- `main` не сливали до готовности продукта; с 29.10 `main` = продукт, ветка `feature/voice-latency` сохранена.
- Fable 5.1 как судья даёт независимую проверку, но упирается в лимиты; аудит 27.10 делали на Opus.

## Открытые вопросы на момент передачи
1. На роботе после установки «последнего» APK пользователь видел старое поведение (тап не работает, костюмы не
   меняются). Файл по ссылке был верный (проверено по содержимому). Ждём проверку версии в диагностике:
   `app: … 0.1.0+0a7aab2.2026-10-29`. Если версия верна — касания на реальном экране ведут себя иначе, чем на эмуляторе.
2. Выход по × закрывает приложение, но Startup Programs RobotOS тут же запускает его снова. Предложено: выход → настройки робота.
3. Экономия ElevenLabs: говорить коротко + показывать полный ответ на экране; кешировать шаблонные фразы (≈ −40–50 %). Не сделано.
4. В шуме робот без сна слушает всех; «не мне» отсекает ~2/3 чужих реплик. Можно слушать только при человеке перед роботом (PersonApi).
5. Лицензии у публичного репозитория нет; `docs/vendor/` — копии документации OrionStar.
6. Ветки mynbay (`feature/robot-face-ui`, `feature/new-ui-voice-latency`) и Collector119 не сливаются — их работа перенесена вручную.
