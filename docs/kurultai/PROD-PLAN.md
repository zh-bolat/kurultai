## 0. Контекст за минуту

- Робот: OrionStar GreetingBot Nova, экран 14" 1920×1080, **RobotOS 10.4**. AgentOS SDK не работает, только RobotAPI
  через `robotservice.jar`. Запуск приложений только через RobotOS Home. Автозапуск — Startup Programs.
- **ADB по Wi‑Fi закрыт.** APK ставится через браузер робота: на ноутбуке в той же сети
  `python3 -m http.server 8090` в папке с APK, на роботе открыть `http://<ip-ноутбука>:8090/`.
- Встроенные ASR/TTS робота ru/kk официально не знают. В Astana Hub мы ушли на серверный голос. Их приложение
  использует TTS робота: **качество казахского нужно проверить первым делом** (задача 1).
- Приложение команды Курултая лежит в `android-app/` (Java + WebView), разбор — `docs/kurultai/app-analysis.md`.
  Читать его перед правками. Справочники по роботу — `docs/astana-hub/` (`context.md`, `robot-setup.md`).
- Вариант A (решение владельца 2026-10-29): **архитектуру не трогаем**. OpenAI вызывается с робота, ключ на роботе.
  Меняем промпт, данные, экраны, тексты. Серверную часть (`backend/`) не используем.

## 3. Задачи на сегодня

### Задача 1. Проверка голоса на роботе (devops, первые 30 минут, блокирует остальное)
1. Положить `apk-archive/Kurultai-SG04-v5.49-AI-ASSISTANT.apk` в папку, поднять `http.server 8090`, поставить через браузер робота.
2. Запуск только через RobotOS Home: три пальца вниз → Все приложения → «AI-помощник Комитета».
3. Ключ OpenAI: скопировать на роботе в буфер, ⚙ → «Вставить ключ из буфера».
4. Задать 3 вопроса по-русски и 3 по-казахски (голосом, удерживая кнопку). Записать: распознаёт ли казахский,

### Задача 2. Характер и промпт (main) — сделано 2026-10-29, осталась проверка на роботе (§6)
Переписать `ASSISTANT_INSTRUCTIONS`, сохранив все правила про официальные источники, запрет URL, `[REPEAT]`,
«Республика Казахстан» полностью, лимит слов. Добавить:
- **Деловой**: отвечает по существу с первого предложения, точные названия органов и должностей, цифры с датой,
  без канцелярита и без «как ИИ-модель».
- **Немного игривый**: допускается одна лёгкая фраза в приветствии или в конце ответа (про себя как робота, про погоду
  в Астане, про то, что он не устаёт). Никогда: шутки про политику, депутатов, партии, государственные символы, религию.
  Если тема серьёзная (обращение гражданина, закон), игривость выключена.
- Актуальность: любой изменяемый факт (дата, должность, статус законопроекта, цифра) брать из снимка quryltai.kz или
  web_search; если не подтверждён, сказать «не нашёл актуальных официальных данных» и предложить, где уточнить.
  Называть дату данных словами («по данным на 29 октября»).
- Приветствия: 4–5 вариантов ru и kk, случайный выбор, в `greetVisitor()` массивы вместо двух строк.
- Персона по решению владельца (§1).
Проверка: 10 контрольных вопросов (§6), ни одной выдумки, ни одной неуместной шутки.

### Задача 2а. Снизить расход OpenAI в 3–5 раз (frontend, 1 час, вместе с задачей 2)
Сейчас web search включён в каждый запрос (1 цент за вызов, 2/3 месячного счёта), а снимок quryltai.kz
(10–15 тыс. токенов) вклеивается без кэша.
1. В `requestOpenAI()` добавлять инструмент `web_search` только по триггерам: вопрос содержит дату, год, «сколько»,
   «когда», «кто сейчас», «статус», «последн», «новост», и их казахские аналоги (`қашан`, `қанша`, `қазір`, `соңғы`).
   В остальных случаях `tools` пустой, модель отвечает из снимка quryltai.kz и справочника Курултая.
2. Порядок частей промпта: сначала неизменный блок (инструкции + справочник + снимок quryltai.kz), в конце вопрос.
   Одинаковый префикс попадает в кэш OpenAI (входные токены $0.02 вместо $0.20 за 1M).
3. Снимок quryltai.kz сократить: комитеты полностью, депутатские запросы последние 30, не 100.
Цель: стандартный режим ≤ $25 в месяц при 200 ходах в день (было ≈ $65).

## 8. Realtime — отменён

Решение владельца 2026-10-29: режим OpenAI Realtime / gpt-live не делаем. Причины: цена за минуты сессии
(в 4–15 раз дороже текстовой схемы), непроверенный казахский, команда уже откатывалась с gpt-live-1 (v5.40).
Единственный режим голоса — стандартный: запись → транскрипция OpenAI → текстовая модель → TTS робота
(план Б по голосу — ElevenLabs через наш сервер, §7). Бюджет ключа OpenAI: $100 в месяц с жёстким лимитом.
