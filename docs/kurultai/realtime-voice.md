# Ақылтай «голос в голос»: OpenAI Realtime вместо цепочки STT → модель → TTS

Статус: **план** (2026-11-09). Решение владельца: перейти на OpenAI Realtime ради скорости ответа; Gemini Live рассмотрен — выбран OpenAI («качественнее», решение владельца 09.11).
Сервер — профиль `kurultai`, worktree `~/astana-hub-robot-wt/kurultai-realtime`, ветка `feature/kurultai-realtime`
от `feature/kurultai-profile`. Astana Hub не меняется.

## Зачем
Замер за 08–09.11 (48 ответов): робот начинает говорить через **3,6 с** (p50) и **8,7 с** (p95) после того,
как человек замолчал. Из них распознавание 1,6 с, модель 1,4 с (6,7 с с веб-поиском), голос ~0,5 с.
Realtime — одна модель слышит и сразу говорит: ожидаем первый звук **~1 с** (проверим пробником, §6).

## Что меняется и что нет
| | сейчас (pipeline) | Realtime |
|---|---|---|
| Протокол робота `WS /v1/live` | — | **тот же**: `hello`, `visitor_arrived`, `interrupt`, `playback_done`; сервер шлёт `ready`, `listening`, `user_speaking`, `user_final`, `thinking`, `turn_start`, `phrase`, `turn_end`, `interrupted`, `ignored`; звук PCM16 24 кГц. **Приложение не переустанавливаем** |
| Звук на вход | Silero VAD → Gemini Flash Lite (OpenRouter) | сервер пересылает микрофон в OpenAI Realtime (16 → 24 кГц), VAD — у OpenAI (`server_vad`) |
| Ответ | gpt-6-luna (OpenRouter) → ElevenLabs Dmitry | `gpt-realtime-2.1` сам говорит голосом OpenAI (`cedar` / `marin` — выберем на слух) |
| База | промпт: персона + правила + материалы админки + снимок quryltai.kz (~23 тыс. токенов) | **те же инструкции** в `session.instructions` (контекст модели 128 тыс. токенов); обновились материалы или снимок — `session.update` перед следующим ответом |
| «Только на Ақылтай / робот» + окно 30 с | `app/kurultai/wake.py`, до модели | ответ не создаётся сам (`create_response: false`); сервер ждёт расшифровку фразы и решает: обращение или окно разговора → `response.create`, иначе фраза удаляется (`conversation.item.delete`) |
| Язык | только кнопка ҚАЗ\|РУС | то же: язык в инструкциях; смена языка (`hello.lang`) → `session.update` |
| Перебить | только «стоп» / «хватит» / «тоқта» | то же: `interrupt_response: false`; «стоп» в расшифровке → `response.cancel` + `interrupted` роботу |
| Веб-поиск | плагин OpenRouter на каждый вопрос | инструмент `web_search(query)` — модель зовёт сама для новостей (существующий код OpenRouter); перед поиском говорит «Сейчас посмотрю» |
| Субтитры | фразы ответа | расшифровка ответа модели (`response.output_audio_transcript.delta`) → `phrase` |
| Журнал вопросов, метрики | как есть | из расшифровок; метрика `live_first_audio_ms` та же — сравним |
| Действия (Telegram/почта/календарь) | — | инструменты Realtime (function calling) — план `assistant-integrations.md` не меняется |

## Переключатель и откат
- `.env` сервера Курултая: `KURULTAI_LIVE_ENGINE=realtime` (по умолчанию `pipeline` — как сейчас).
- `KURULTAI_OPENAI_API_KEY` — **прямой ключ OpenAI** (OpenRouter Realtime не поддерживает). Только в `.env` сервера.
- `KURULTAI_REALTIME_MODEL=gpt-realtime-2.1`, `KURULTAI_REALTIME_VOICE=cedar`.
- OpenAI недоступен / ошибка сессии → эта сессия робота идёт старым pipeline (робот ничего не замечает).
- Откат целиком — `KURULTAI_LIVE_ENGINE=pipeline` и перезапуск контейнера, 1 минута.

## Цена (оценка, проверить по официальному прайсу)
Realtime тарифицируется токенами: аудио на вход ~$32/млн, на выход ~$64/млн, кэш входа ~$0,40/млн; по сторонним
оценкам ≈ $0,05 за минуту разговора у `gpt-realtime-2.1` и ≈ $0,016 у `-mini`. Инструкции (~23 тыс. токенов)
идут в каждый ответ, но кэшируются. Пока робот спит — ничего не платим (сессия закрыта). Поставить лимит на ключ.

## Риски
1. **Казахский** — главный риск: голос OpenAI с акцентом или ошибками в казахском. Проверяем первым (пробник §6).
2. **Голос Dmitry теряется** — будет голос OpenAI.
3. **Задержка фильтра обращения:** первая фраза с «Ақылтай» ждёт расшифровку (по отзывам она может приходить
   пачкой в конце фразы, +0,3–1 с). Внутри окна разговора — без ожидания.
4. **Эхо:** робот слышит свой голос. Пока робот говорит, сервер не создаёт ответов, только ловит «стоп».
5. **Сессия до 60 мин** у OpenAI — переподключаемся незаметно, контекст разговора короткий.

## Этапы
1. **Пробник** (`backend/scripts/realtime_probe.py`): 10 вопросов ru/kk (из записей с робота или синтез Dmitry) →
   Realtime с нашими инструкциями → время до первого звука и аудио ответов на прослушку. **Решение «идём / нет»
   — по замеру и на слух.**
2. Движок `realtime` на сервере за переключателем; тесты с фейковым Realtime-сервером; фильтр обращения, «стоп»,
   язык, веб-поиск, журнал.
3. Выкатка с `KURULTAI_LIVE_ENGINE=realtime`, сравнение `live_first_audio_ms` до/после на роботе.
