## 2026-10-30: «null» в ответах, данные вкладок, обновление
- **Причина «null».** Модель `gpt-6-luna` иногда тратит весь лимит токенов на размышление и возвращает `content: null`.
  Android-версия org.json превращает JSON null в строку "null", приложение показывало и озвучивало её как ответ.
  Воспроизведено: при нехватке лимита reasoning=300 из 300, content=null.
  Исправлено:
  - ответы по данным приложения идут с `reasoning.effort=none` (размышление не нужно, ответ 1,5–3 с), лимит 1000;
  - вопросы о новостях: `effort=low`, лимит 1500;
  - если ответ всё же пустой — повтор без размышления с лимитом 1500;
  - все поля JSON читаются через `jsonText()` / `text()`, которые не подставляют "null" (ответ модели, распознавание,
    озвучка, имена и должности депутатов, номера и темы запросов);
  - сообщения об ошибках без "null": вместо пустого текста исключения — его тип.
- **Данные вкладок в модели.** Снимок quryltai.kz (законопроекты, планы, комитеты с составами, депутатские запросы) идёт
  в каждый запрос. Было: 12 законопроектов из 57 и до 100 запросов. Стало: все законопроекты (до 100), до 120 последних
  запросов (загружается до 200). Добавлены готовые итоги, потому что модель ошибалась при подсчёте: законопроекты по статусам,
  число комитетов, число членов в каждом. Проверено: 8 комитетов, 40 на рассмотрении, 8 подписано, 5 отозвано.
- **Обновление.** Раньше раз в сутки. Теперь раз в час, пока приложение открыто, и при каждом запуске. После неудачной
  попытки следующая через 5 минут, а не каждые 30 секунд. Вкладки mynbayy получают новые данные через `onQuryltaiData`.
- **Веб-поиск.** Раньше включался почти на любой вопрос: в триггерах было слово «Курултай». Теперь `needsWebSearch()`
  включает его только для новостей, прошедших событий и расписания. Вопросы по данным приложения отвечаются по снимку.
- **Кэш промпта.** Текущее время перенесено из системного промпта в сообщение пользователя. Одинаковый префикс
  (≈17,5 тыс. токенов) кэшируется: вопрос по данным стоит ≈0,02 цента вместо 0,22, вопрос с поиском ≈1 цент.
- Стенд проверки: 14 вопросов (данные, новости, казахский, длинные списки, «кто ты», погода), 0 пустых ответов, $0.039 за всё.
