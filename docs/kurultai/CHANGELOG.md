# Что изменено относительно присланного v5.49

## 2026-10-29
- Свой пакет `kz.ustem.kurultai` и название «AI-помощник Курултая»: ставится рядом с приложением команды, обновляется поверх себя.
- Подпись release своим keystore (`android-app/release.keystore` + `secrets.properties`, вне git).
- `versionName` = `5.50-<git sha>-<дата>`, `versionCode` = 74 + число коммитов (считается при сборке).
- **Единственный провайдер — OpenRouter.** Убраны ключ OpenAI, его ввод через буфер/USB, Responses API и `gpt-4o-transcribe`.
  - Ответы: `openai/gpt-6-luna` (меняется в ⚙ → «Модель ответа»).
  - Распознавание речи: WAV с микрофона → `google/gemini-3.1-flash-lite` как `input_audio` (⚙ → «Модель распознавания речи»).
    Проверено на русских и казахских клипах: дословно, ≈2 с, ≈0,015 цента за фразу.
  - Ключ OpenRouter вшивается из `secrets.properties` (`OPENROUTER_KEY`) и при первом запуске сохраняется в Keystore.
- Исправлено: без ключа OpenAI приложение уходило в «деморежим» и показывало заготовки вместо ответа модели
  (флаг `directAiReady` в `app.js` зависел от ключа OpenAI).
- Веб-поиска по официальным доменам в режиме OpenRouter нет: модель опирается на снимок quryltai.kz и обязана говорить,
  если актуальных данных у неё нет.
