# Курултай — материалы проекта

- `app-analysis.md` — **разбор присланного приложения** (v5.49, 2026-10-29): структура, стек, как общается
  с роботом, что берём, что переделываем, план работ.
- `RELEASES.md` — **стабильные сборки** (версия, sha256, где лежит APK, как откатиться).
- `CHANGELOG.md` — что изменено относительно присланного v5.49.
- `PROD-PLAN.md` — план вывода в прод.
- `TZ.md` — техническое задание (что должен делать робот на Курултае) — **ещё не получено**.

Исходники лежат в корне репозитория:
- `android-app/` — Android-приложение (Java + WebView): исходники команды v5.49, дизайн mynbayy и наши правки (см. `CHANGELOG.md`);
- `backend/` — их необязательный Node-шлюз к OpenAI (не используется: приложение ходит в OpenRouter);
- `apk-archive/` — их 110 APK v1.0 → v5.49 и наши сборки `Kurultai-Ustem-*` (не в git).

Опыт и справочники по роботу — в `../astana-hub/` (читать `HISTORY.md` первым).
