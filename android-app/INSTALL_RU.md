# Установка на робота

Готовый демонстрационный APK находится в соседней папке `apk`.

## Через ADB

1. Включите на роботе режим разработчика и отладку по USB.
2. Подключите робота к компьютеру.
3. Выполните:

```bash
adb devices
adb install -r Kurultai-AI-Assistant-OrionStar-SG04-v2.1.apk
```

Пакет приложения: `kz.kurultai.assistant`.

## Если OrionStar использует собственную панель управления

Загрузите APK как стороннее/корпоративное приложение и назначьте его запускаемым приложением. Для автоматического старта может потребоваться настройка kiosk mode в панели OrionStar либо добавление приложения в белый список производителем.

## Перед установкой

- требуется Android 6.0 или новее;
- интерфейс оптимизирован для 14-дюймового Full HD экрана OrionStar OS-R-SG04;
- ориентация экрана фиксируется горизонтально;
- основной голосовой ввод и озвучивание работают через OrionStar RobotOS SDK; Android-аудиосервис используется как резервный;
- для прямого ChatGPT-режима введите API-ключ в меню ⚙ и убедитесь, что у проекта OpenAI API активен биллинг;
- без сети приложение работает в демонстрационном режиме;
- реальный AI подключается напрямую по API-ключу или через дополнительный защищённый серверный шлюз.

Текущий файл подписан демонстрационным ключом Android. Для тиражирования необходимо создать корпоративный keystore и хранить его отдельно от исходного кода.

## Запуск через RobotOS

После установки не запускайте приложение кнопкой Run из Android Studio.

1. Проведите тремя пальцами вниз по экрану робота.
2. Откройте «Все приложения».
3. Выберите «AI-помощник Комитета».

Для автоматического запуска откройте «Настройки» → «Другие настройки» → «Приложения при загрузке» и выберите «AI-помощник Комитета». В APK зарегистрировано действие `action.orionstar.default.app`, необходимое RobotOS для этого режима.

## Не набирать API-ключ вручную

Есть два варианта:

1. Скопировать новый ключ в буфер обмена робота, затем открыть ⚙ и нажать **Вставить ключ из буфера**. После импорта приложение очищает буфер.
2. Подключить робот по USB и запустить `provision_openai_key.command`. Ключ вводится в терминале скрыто, а на экране робота нужно подтвердить сохранение.

Никогда не используйте ключ, опубликованный в переписке или на скриншоте: сначала отзовите его и создайте новый.
