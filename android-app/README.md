# AI-помощник Комитета Курултая

Автономное Android-приложение для демонстрации на роботизированной платформе OrionStar OS-R-SG04. Интерфейс адаптирован под 14-дюймовый Full HD сенсорный экран, системное масштабирование RobotOS/Android 9 и работает без интернета в демонстрационном режиме.

## Возможности

- анализ законопроекта и краткая справка;
- подготовка к заседанию и проект выступления;
- сводка обращений граждан и региональных рисков;
- формирование проекта поручения;
- голосовой ввод и озвучивание через официальный OrionStar RobotOS SDK с резервным Android-аудиосервисом;
- прямое подключение к OpenAI Responses API;
- зашифрованное хранение API-ключа через Android Keystore;
- веб-поиск для актуальных ответов с запретом выдавать неподтверждённые данные за факты.
- аналитический центр Комитета по цифровизации, инновациям и науке;
- интерактивная карта регионов Казахстана;
- дашборды по цифровизации, инновациям, науке, кибербезопасности и законотворчеству.

Интерактивная GIS-карта использует точную SVG-геометрию из `galymorg/new_qazaqstan_GeoJSON` (MIT), подготовленную на основе административного слоя `arodionoff/geokz` 2024 года (CC BY 4.0). Карта содержит 20 актуальных единиц: 17 областей и города Астана, Алматы и Шымкент. Геометрия хранится внутри приложения для полностью автономной работы.

## Прямое подключение OpenAI

В приложении откройте ⚙, вставьте API-ключ OpenAI и нажмите **Сохранить ключ**. Ключ шифруется ключом из Android Keystore и не показывается повторно. Приложение обращается к OpenAI Responses API по HTTPS, использует модель `gpt-6-astra` и инструмент веб-поиска.

Подписка ChatGPT и биллинг OpenAI API являются отдельными продуктами. У API-проекта должен быть активный платёжный метод и доступный баланс.

Прямое хранение ключа на физическом устройстве менее безопасно, чем серверный шлюз. Для пилотной демонстрации используйте отдельный API-проект с небольшим лимитом расходов и после мероприятия отзовите ключ.

## Дополнительный AI-шлюз

В настройках приложения указывается URL. Приложение отправляет POST JSON:

```json
{"message":"вопрос пользователя","language":"ru","context":"deputy_assistant"}
```

Сервер должен вернуть JSON `{"answer":"текст ответа"}` либо обычный текст. Готовая реализация находится в папке `server/`. Для постоянной эксплуатации этот вариант безопаснее прямого режима.

## Голосовой режим OrionStar

Версия для SG04 использует локальный голосовой контур робота:

1. RobotOS распознаёт речь с микрофона (Android-распознавание с приоритетом офлайн-режима используется как резервное).
2. В OpenAI отправляется только распознанный текст — аудиозапись не передаётся.
3. Текстовый ответ озвучивается через RobotOS TTS, с резервным Android TTS.
4. После завершения озвучивания микрофон снова включается автоматически.

Для ответа GPT требуется Wi-Fi. Полностью офлайн-распознавание в резервном Android-режиме зависит от установленных на роботе языковых пакетов.

Минимальная версия Android — 6.0 (API 23). Приложение собрано без AndroidX и внешних библиотек для максимальной совместимости.
